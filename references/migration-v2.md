# 从 v1 迁移

这次是设计行为与视觉默认值的重构，不是框架迁移。旧版许可证和第三方声明保留。

1. 用新的 SKILL.md 替换入口，并同步 references。不要同时保留一份强制 Hero 的旧系统提示。
2. `metaAntTheme` 导出保留，但预设色从默认蓝改为 Graphite & Iris；这是有意的视觉变更。已有产品品牌不应被无意覆盖，先在主题映射层比较。
3. `FocusHero` 原 props 保留并标记 deprecated，布局改为紧凑中性摘要。它不再依赖 Card 或浅色整块底。旧项目覆盖 `.ant-card-body` 的自定义样式需要迁移。
4. `MetricBand/AttentionList` 可继续用于真实指标/异常，新页面不默认引入。新 CSS 缩减 KPI 高度并移除默认投影；不得靠补回大 Card 样式恢复旧问题。
5. 历史任务改用 TaskSummary history，业务快照和当前任务状态分离；旧 actions 要人工确认权限与语义后迁移，不能机械改名。
6. 主题只替换颜色和尺寸；重复完成摘要、冻结证据、资源编辑器导航等需按页面模板真实重构。

## 升级切片

先选一个交付详情页，覆盖当前/历史/失败/待确认；再复用到结果与审核页；资源编辑器单独验证草稿与复制行为。不要同一轮升级依赖、重写路由和权限。

## 不能宣称的兼容性

保留 TS 导入/props 不保证现有 DOM 选择器和截图快照不变。目标是可控的视觉重构，不是像素兼容。本仓库的独立 Token specimen 不能代替宿主 AntD 页面验收。
